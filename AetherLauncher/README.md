# AetherLauncher v0.4.2

A refreshed Windows launcher interface with GitHub release update checking.

Install: Windows 10/11, Python 3.11+, run `install.bat`, then `start.bat`.
Minecraft Java default: 26.3. Java 25 or newer is required.
Updater checks the latest public GitHub release at `noa123456789/AetherLauncher`.
Attach a ZIP asset to each GitHub release. The updater preserves user config and Minecraft game files.
Offline Java profile is only for servers configured with `online-mode=false`; configure server authentication.
