# AetherLauncher v0.4

A refreshed Windows launcher for Minecraft Java 26.3 and Bedrock.

## Setup
1. Windows 10/11 64-bit and Python 3.11+.
2. Extract this folder.
3. Run `install.bat`, then `start.bat`.
4. Choose Minecraft Java 26.3, enter your offline profile name and download/install.
5. Start the game.

## Minecraft 26.3
Minecraft Java 26.3 is the default stable release in this launcher. It requires Java 25 or newer. Install Java 25 and, if automatic detection does not find it, select `java.exe` in Settings.

## Offline Java profile
This mode is only for servers configured with `online-mode=false`. It does not authenticate ownership of a Minecraft account. Anyone may impersonate another username, so use an authentication plugin such as AuthMeReloaded and secure permissions.

## Bedrock
The Bedrock page opens the official Minecraft for Windows app. It does not download or bypass Microsoft Store licensing/authentication.

Game files: `%APPDATA%\AetherLauncher\.minecraft`
Config: `%APPDATA%\AetherLauncher\config.json`
